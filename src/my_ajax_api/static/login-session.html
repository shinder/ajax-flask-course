Cookie 在哪裡？

登入後打開 DevTools 的 Application（Chrome）或 Storage（Firefox）面板，Cookies 底下會多一筆 session。 Network 面板裡登入回應的 Set-Cookie 標頭與之後請求的 Cookie 標頭也看得到。 但下面用 document.cookie 讀出來的結果是空的，因為伺服器設了 HttpOnly， JavaScript 碰不到它，就算頁面被注入惡意程式碼也偷不走。
